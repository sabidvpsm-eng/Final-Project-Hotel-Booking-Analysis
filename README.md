# FInal-Project-Hotel-Booking-Analysis

## Project Overview
This project analyses hotel booking data using Python to identify booking trends, cancellation patterns, seasonal demand, market segments, and pricing performance.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Tasks
- Data loading and initial overview
- Data cleaning and preprocessing
- Missing value handling
- Duplicate handling
- Data type correction
- Derived column creation
- Univariate analysis
- Bivariate analysis
- Multivariate analysis
- GroupBy analysis
- Pivot table analysis
- Correlation analysis
- 10+ visualisations
- Key insights and recommendations

## Main Findings
- City Hotel receives more bookings than Resort Hotel.
- City Hotel also has a higher cancellation rate.
- Booking demand increases during the summer months and peaks around August.
- Average Daily Rate also increases during peak summer months.
- Longer lead times are associated with higher cancellation levels.
- Online Travel Agents generate the largest share of bookings.
- Group bookings show relatively high cancellation rates.

## Files
- `Hotel_Booking_Analytics.ipynb` — Complete Python analysis and visualisations
- `hotel_bookings.csv` — Original raw dataset

## Dataset Source
Hotel Booking Demand dataset from Kaggle.

## Conclusion
The analysis shows how hotel booking data can be used to understand customer behaviour, cancellation patterns, seasonal demand, and pricing performance. These insights can support better pricing, booking management, marketing, and operational decisions.
